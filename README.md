# Login and Registration System in C++ 🔐

This is Task 2 of my C++ Programming Internship at CodeAlpha. It is a console application that handles user registration, prevents duplicate usernames, and authenticates login credentials using file handling.

## Features
* User Registration with unique usernames and passwords
* Duplicate username prevention
* User Authentication against stored data in database.txt
* Local data persistence using C++ file streams (fstream)

## Tech Stack
* Language: C++
* Libraries: iostream, fstream, string
